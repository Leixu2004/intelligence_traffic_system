你是交通监控分析师。分析以下监控画面，并按 JSON 输出结论。

需要回答：
1. 是否存在事故？
2. 事故类型（追尾/侧翻/碰撞行人/剐蹭/无）；
3. 涉及车辆数；
4. 严重程度（无/轻微/中等/严重）；
5. 建议处置措施。

只输出一个 JSON 对象，不要 Markdown 代码块，不要额外解释文字。字段固定为：

{
  "accident": true 或 false,
  "accident_type": "追尾|侧翻|碰撞行人|剐蹭|无",
  "vehicle_count": 整数或 null,
  "severity": "无|轻微|中等|严重",
  "location": "画面中可判断的位置描述，无法判断填 null",
  "lane": "受影响车道描述，无法判断填 null",
  "actions": ["处置建议，按优先级排列"],
  "evidence": "画面中支持结论的可见依据，一句话"
}

判定纪律：画面中没有可见碰撞、变形、倒地、异常停止等证据时，accident 必须为 false，
severity 必须为 "无"，不要为了给出结论而编造。不确定的字段填 null。
